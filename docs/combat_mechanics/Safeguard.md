# Safeguard

**Type:** Combat

Unbroken Broken Status Effects is a unique Status Effect . It decreases the damage taken by the target until the target is weakness broken, with the drawback of increasing the targets damage taken while weakness broken. 1.Enemies 1.c Shadow

| Icon | Name | Description |
| --- | --- | --- |
|  | Safeguard | DMG taken decreases. This effect is removed when Weakness is Broken. This unit's action will be delayed further when it is Weakness Broken and also takes increased DMG. |
|  | Safeguard Broken | DMG taken increases. This effect is removed and DMG taken decreases when this unit recovers from being Weakness Broken. |
