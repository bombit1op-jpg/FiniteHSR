# Elation DMG

**Type:** Combat

The more Punchline taken into account, and the higher the Elation and Character Level, the greater the Elation DMG dealt. Elation DMG is not affected by DMG Boost effects. is a type of damage associated with characters following the Path of Elation . In combat, Elation DMG is displayed as rainbow colored damage numbers.

## Formulas

**`Elation DMG= Base DMG_Attacker× Original Elation DMG Multiplier_Attacker\\ × CRIT Multiplier_Attacker× Elation Multiplier_Attacker\\ × Punchline Multiplier_Attacker× Merrymake Multiplier_Attacker\\ × DEF Multiplier_Target× RES Multiplier_Target\\ × Vulnerability Multiplier_Target× DMG Mitigation Multiplier_Target\\ × Broken Multiplier_Target`**

**`Base DMG=Level Multiplier× Ability Multiplier`**

**`Ability Multiplier=Base Ability Multiplier+Elation DMG Multiplier Increase`**

**`Elation Multiplier=1+Elation`**

**`Punchline Multiplier= cases1+ Certified Banger× 5Certified Banger+240 if produced by the Certified Banger state\\1+ Punchline× 5Punchline+240 otherwise\\ cases`**

**`Merrymake Multiplier=1+Merrymake`**

**`CRIT Multiplier = cases 1 + CRIT DMG if attack scores a CRIT hit\\ 1 otherwise\\ cases`**

**`DEF Multiplier= Level_Attacker+20 matrix(Level_Enemy+20)\\× max\0,1+\%DEF Bonus-\%DEF Reduction-\%DEF Ignore\\\+ Level_Attacker+20 matrix`**

**`RES Multiplier = 1 - (RES_Target - RES PEN_Attacker)`**

**`Vulnerability Multiplier= 1+Elation DMG Vulnerability+All-Type Vulnerability`**

**`DMG Mitigation Multiplier_Total= (1-DMG Mitigation_1)× (1-DMG Mitigation_2)\\× (1-DMG Mitigation_3)×`**

**`Broken Multiplier = cases 0.9 if enemy has Toughness\\ 1.0 if enemy Toughness is broken\\ cases`**
