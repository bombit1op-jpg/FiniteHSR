# Healing

**Type:** Combat

refers to the regeneration of HP . This can be done via consumables , character abilities, special buffs, Space Anchors, etc. Healing can be boosted by the Outgoing Healing Boost stat. ## Formulas

**`Healing Boost Multiplier= 1+Outgoing Healing Boost_Healer\\ +Incoming Healing Boost_Target\\ -Incoming Healing Reduction_Target`**
