# Skill Point

**Type:** Combat

Skill Points are a type of resource shared by the player's team to perform Skills, represented by array(s) of four-point star icons. They are shared by the player's team. The default number of Max Skill Points is 5, and the team starts with Points upon entering battle. If the maximum Skill Point is increased, the HUD will add empty stars, up to and if the current amount of Skill Points is more than 10, the 10th Skill Point star icon will be shown with another star behind it. Most Skills consume a Skill Point to use, and most Basic Attacks generate a Skill Point. However, there are exceptions to the rule, such as enhanced Basic Attacks that do not generate and/or consume any Skill Points, and Skills that consume an alternative resource instead of Skill Points. Certain characters, such as Dan Heng • Imbibitor Lunae and Sparxie , have a personal resource named Squama Sacrosancta and Thrill , respectively, which are shown on their character HUD, prioritized for consumption over standard Skill Points, and whose consumption is considered consuming an equal amount of Skill Points (for effects such as Yao Guang 's Talent and Propagation Blessings ).
