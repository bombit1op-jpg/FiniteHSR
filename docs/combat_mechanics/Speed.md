# Overview

**Type:** Combat

Data Speed Stats Speed , often abbreviated as SPD , is one of the stats in Honkai: Star Rail , used by both characters and enemies. In combat, it determines Action Value ( AV ), and consequently the order and frequency in which characters and enemies will act. Action Value can be set to visible in the Other Settings tab of the Settings menu. SPD = Base SPD × ( + SPD % ) + Flat SPD {\displaystyle \text{SPD} = \text{Base SPD} \times (1 + \text{SPD} \%) + \text{Flat SPD}} Base Action Value is the time between turns for each unit and is calculated based on their SPD: Base Action Value = SPD {\displaystyle \text{Base Action Value} = \frac{10000}{\text{SPD}}} Turn order is determined as follows: At the beginning of the battle, each unit's Action Value, representing the amount of time until that unit's next turn, is set to their Base Action Value. At the beginning of the battle, effects that take effect upon entering battle, including SPD/AV modifying effects, are triggered on characters from left to right. The unit with the lowest Action Value, i.e. shortest time until their next turn, is selected to be the next active unit. All units subtract that lowest Action Value from their current Action Value, representing the progress of time until the next active unit's turn. The active unit starts their turn. All DoTs on the active unit deal damage. If the active unit is player-controlled and Auto mode is not enabled, the player has the opportunity to cast any pre-action Ultimate(s). Pre-action Ultimates cannot advance the action of the active unit (e.g. by the set effect of Eagle of Twilight Line ), since at this point the active unit's Action Value is already zero. The active unit acts, resetting their Action Value to their Base Action Value. The player can queue any post-action Ultimates during the action animation. Any post-action Ultimates queued during the action animation execute. Post-action Ultimates can advance the next action of the active unit, since at this point its Action Value has been reset. The active unit's turn ends, ticking down any Status Effects on the active unit. Some Status Effects only tick down if they were present at the beginning of the active unit's turn. Repeat from #3. Over a long time, the number of turns a unit takes is proportional to their Speed.

## Formulas

**`SPD = Base SPD × (1 + SPD \%) + Flat SPD`**

**`Base Action Value = (10000)/(SPD)`**

**`Action Value_New = Action Value_Old × (SPD_Old)/(SPD_New)`**

**`Action Value_New = max (0, Action Value_Old - Base Action Value × (Action Advancement\% - Action Delay\% ) )`**

## Sim timing rules

- **Delay is the inverse of Advance.** Net shift is `advance − delay` on the combined formula above. A 50% delay puts the target 50% of a base AV behind its natural spot; to make it act immediately you must Advance **150%** (own 100% to re-arm + 50% to cancel the delay). A 100% Advance exactly cancels a prior 100% Delay.
- **Advance applied to a unit during its own regular turn is lost.** The active unit's AV is already 0 ("Pre-action Ultimates cannot advance the action of the active unit"), the advance clamps to 0 and `endTick` re-arms the unit at base AV. E.g. **DHIL E2** (100% post-ult Advance) is inert for a pre-action ult inside DHIL's own auto turn — DHIL has no "turn does not end" chain, so nothing keeps the Advance (bonus-turn rule does not apply to him). Real Advance only lands on his *next* queued action when the ult fires out-of-turn (manual/`outOfTurnUlts`).
- **Exception — "the current turn does not end" chains (Bonus Turns).** While a unit is inside a bonus-turn loop (Qingque tile draws, Archer Circuit Connection, Blade Hellscape, Boothill Standoff, Seele Resurgence, Firefly E2), the turn is not finished, so an Advance from an outside source (e.g. Robin's Concerto, Sunday's Skill) targets the unit's next genuinely queued action and is NOT lost. See `Extra Turn.md`.
- **Bonus Turns do not tick durations.** Buff/Debuff duration, DoT, SPD states all freeze across extra turns; only the acting unit's own "state lasts N extra turns" budgets (e.g. SW LV.999 Godmode's Enhanced-Basic uses, which count extra turns per `It's a Feature, Not a Bug`) decrement.
