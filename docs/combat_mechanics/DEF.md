# Overview

**Type:** Combat

Data This article is about the stat.For the Light Cone, see Defense . DEF Stats DEF is one of the stats in Honkai: Star Rail , used by both characters and enemies. It is a stat that decreases DMG taken. Some character skills will also deal DMG or create shields based on DEF. It multiplies incoming DMG by the following: DEF Multiplier = − ( DEF DEF + + × Level Attacker ) {\displaystyle \text{DEF Multiplier} = 1 - (\frac{\text{DEF}}{\text{DEF} + 200 + 10 \times \text{Level}_\text{Attacker}})} When a unit's DEF becomes to DEF Reduction/Ignore, the DEF Multiplier will reach the cap of 100%.

## Formulas

**`DEF Multiplier = 1 - ((DEF)/(DEF + 200 + 10 × Level_Attacker))`**

**`Base DEF = (DEF_Character + DEF_Light Cone)`**

**`Total DEF = Base DEF × (1 + \% DEF Bonus - \% DEF Reduction) + Additive DEF Bonus`**

**`Base DEF_Enemy = 200 + 10 × Level`**

**`DEF Multiplier_Enemy= Level_Attacker+20(Level_Enemy+20)× max\0,1+\%DEF Bonus-\%DEF Reduction-\%DEF Ignore\+Level_Attacker+20`**

**`Base DEF_Trotter = 300 + 15 × Level`**
