# Overview

**Type:** Combat

Data ATK Stats ATK is one of the stats in Honkai: Star Rail , used by both characters and enemies. It is the stat that most character and enemy attacks deal DMG based on. Characters' Base ATK is determined by their level and their equipped Light Cone 's level, while percentage and additive ATK bonuses can be obtained from Relics , Light Cone abilities, character skills, etc. Base ATK = ( ATK Character + ATK Light Cone ) {\displaystyle \text{Base ATK} = (\text{ATK}_\text{Character} + \text{ATK}_\text{Light Cone})} Total ATK = Base ATK × ( + Percentage ATK Bonus ) + Additive ATK Bonus {\displaystyle \text{Total ATK} = \text{Base ATK} \times (1 + \text{Percentage ATK Bonus}) + \text{Additive ATK Bonus}}

## Formulas

**`Base ATK = (ATK_Character + ATK_Light Cone)`**

**`Total ATK = Base ATK × (1 + Percentage ATK Bonus) + Additive ATK Bonus`**
