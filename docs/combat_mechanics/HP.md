# Overview

**Type:** Combat

Data HP Stats HP is one of the stats in Honkai: Star Rail , used by both characters and enemies. It determines the amount of DMG that a character or enemy can sustain before dying. Some character skills may also deal DMG or heal based on HP. Characters' Base HP is determined by their level and their equipped Light Cone 's level, while percentage and additive HP bonuses can be obtained from Relics , Light Cone abilities, character skills, etc. Base HP = ( HP Character + HP Light Cone ) {\displaystyle \text{Base HP} = (\text{HP}_\text{Character} + \text{HP}_\text{Light Cone})} Total HP = Base HP × ( + Percentage HP Bonus ) + Additive HP Bonus {\displaystyle \text{Total HP} = \text{Base HP} \times (1 + \text{Percentage HP Bonus}) + \text{Additive HP Bonus}}

## Formulas

**`Base HP = (HP_Character + HP_Light Cone)`**

**`Total HP = Base HP × (1 + Percentage HP Bonus) + Additive HP Bonus`**
