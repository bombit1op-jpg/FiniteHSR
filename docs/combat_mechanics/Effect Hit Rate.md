# Effect Hit Rate

**Type:** Combat

Stats is one of the stats in Honkai: Star Rail , used by both characters and enemies. It increases the probability of attacks inflicting debuffs on a target. Real Chance = Base Chance × ( + Attacker ) × ( − Effect RES Target ) × ( − Debuff RES Target ) {\displaystyle \begin{align} \text{Real Chance} ={} \text{Base Chance} \\ \times (1 + \text{Effect Hit Rate}_\text{Attacker}) \\ \times (1 - \text{Effect RES}_\text{Target}) \\ \times (1 - \text{Debuff RES}_\text{Target}) \end{align}} Relic Sets
