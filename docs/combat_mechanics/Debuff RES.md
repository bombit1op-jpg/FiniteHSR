# Debuff RES

**Type:** Combat

Stats are stats in Honkai: Star Rail that decrease the probability of corresponding debuffs being applied, alongside Effect RES . Real Chance = Base Chance × ( + Effect Hit Rate Attacker ) × ( − Effect RES Target ) × ( − Target ) {\displaystyle \begin{align} \text{Real Chance} ={} \text{Base Chance} \\ \times (1 + \text{Effect Hit Rate}_\text{Attacker}) \\ \times (1 - \text{Effect RES}_\text{Target}) \\ \times (1 - \text{Debuff RES}_\text{Target}) \end{align}} Consumables
